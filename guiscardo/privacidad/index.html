Política de privacidad de Guiscardo

Última actualización: 17 de noviembre de 2026

Guiscardo es un asistente personal privado, creado y operado por Sebastián Prieto (en adelante, "el responsable") para su uso propio. Esta política explica qué información de Google utiliza Guiscardo, para qué, cómo se guarda y cómo se puede eliminar.

1. Quién puede usar Guiscardo

Guiscardo no es un servicio abierto al público. Solo lo usa el responsable, con las cuentas de Google que él mismo autorizó. No acepta registros de otras personas.

2. Información de Google a la que accede

Con la autorización expresa del titular de la cuenta, Guiscardo puede acceder a:

  • Gmail: correos, remitentes, asuntos y adjuntos, y la posibilidad de crear borradores y enviar mensajes.
  • Google Calendar: calendarios y eventos, y la posibilidad de crearlos o modificarlos.
  • Google Drive: archivos y documentos, y su contenido.
  • Datos básicos de la cuenta: nombre y dirección de correo, para identificar la cuenta conectada.

3. Para qué se usa

La información se usa solo para entregar las funciones que el propio responsable pide: leer y resumir correos, redactar respuestas, organizar la agenda, encontrar documentos y preparar recordatorios. Las acciones que envían, crean o modifican contenido (por ejemplo, enviar un correo) se realizan solo a pedido del responsable.

4. Lo que no se hace

  • No se venden ni se ceden datos a terceros.
  • No se usan para publicidad ni para crear perfiles publicitarios.
  • No se usan para entrenar modelos de inteligencia artificial generales.
  • Ninguna persona lee los datos, salvo el propio responsable, o cuando sea necesario por seguridad o por obligación legal.
El uso y la transferencia de la información recibida de las API de Google por parte de Guiscardo cumplen la Política de Datos del Usuario de los Servicios de API de Google, incluidos los requisitos de Uso Limitado (Limited Use).

5. Servicios que intervienen

Para funcionar, Guiscardo envía el contenido necesario de cada solicitud a un proveedor de modelos de lenguaje que procesa el texto y devuelve la respuesta. Ese proveedor actúa solo como procesador para entregar la función pedida y no usa los datos para entrenar sus modelos. La conversación con Guiscardo ocurre por un chat privado de Telegram.

6. Almacenamiento y seguridad

  • Las credenciales de acceso a Google (tokens) se guardan cifradas o con acceso restringido en el equipo del responsable, y nunca se publican.
  • Guiscardo no guarda copias completas del correo, el calendario ni los archivos. Puede conservar notas breves, como pendientes y resúmenes, para el seguimiento de tareas.
  • La comunicación con Google se hace siempre por conexiones cifradas (HTTPS).

7. Conservación y eliminación

Las notas y resúmenes se conservan mientras sean útiles para el responsable y se pueden borrar en cualquier momento. El acceso a la cuenta de Google se puede revocar cuando se quiera desde myaccount.google.com/permissions. Al revocarlo, Guiscardo deja de acceder de inmediato y se eliminan los tokens guardados.

8. Cambios a esta política

Si esta política cambia, se actualizará esta página con una nueva fecha.
